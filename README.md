# Object-Oriented Java Card Game Simulation

> **A Java card game simulation demonstrating dealer-player card distribution logic, deck management, and round state tracking.**

[![Java](https://img.shields.io/badge/Language-Java-ED8B00?logo=openjdk&logoColor=white)](https://oracle.com/java)
[![OOP](https://img.shields.io/badge/Concept-Object--Oriented%20Programming-blue)](https://github.com/keerthi19hub)

---

## 1. Project Overview

The **Card Game Simulation** is an object-oriented Java application modeling the foundational mechanics of card distribution, player hand evaluation, and dealer state transitions.

---

## 2. Architecture & Classes

- `Card.java`: Models card rank, suit, and face value.
- `Dealer.java`: Encapsulates deck shuffling, hand dealing, and card distribution logic.
- `Main.java`: Execution driver conducting game rounds and outputting player hand results.

## 4. Compilation & Running

```bash
# 1. Clone repository
git clone https://github.com/keerthi19hub/cardgame-repo.git
cd cardgame-repo

# 2. Compile Java source files
javac *.java

# 3. Run simulation
java Main
```
